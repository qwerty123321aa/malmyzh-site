## Исходное состояние

Python 3.10+ без серверных зависимостей, 7 страниц, статическая сборка в docs. GitHub Actions запускает проверку и публикует Pages. Сохраняем эту архитектуру и старые URL.

Работают: ссылки на источники, подписи реальных фотографий, мобильное меню, просмотр снимков, карта OSM и статические диаграммы.

Недостатки: нет поиска, отдельных страниц производства, истории, галереи и обновлений; одинаковое description; нет canonical, Open Graph, sitemap и robots; 404 повторяет главную из-за неработающей замены строки; галерея без переключения кадров и фильтров; нет Leaflet и Plotly; JPEG без современных вариантов; общая страница Python смешивает компоненты и содержание.
