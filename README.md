# Малмыж — атлас месторождения

Учебный информационный сайт на Python о Малмыжском месторождении в Хабаровском крае. Светлый адаптивный дизайн, семь страниц, фотографии с подписями, SVG-схемы и проверяемые источники.

## Страницы

Главная, о месторождении, расположение, полезные ископаемые, значение для региона, экология, источники и изображения.

## Запуск

Python 3.10 или новее. Сторонние библиотеки не требуются.

```sh
python3 app.py serve
```

Откройте http://127.0.0.1:8000. Python создаёт HTML при каждом запросе. Другой порт: `python3 app.py serve --port 8080`.

## Сборка и проверка

```sh
python3 app.py build
python3 app.py check
```

Сборка записывается в `docs/`. Можно открыть `docs/index.html` напрямую. Проверяются локальные ссылки, якоря, файлы изображений, alt-тексты, подписи и заголовки.

GitHub Pages не запускает Python: Python генерирует страницы при публикации, а Pages обслуживает готовые файлы. Python остаётся основой проекта; отдельный сервер не нужен.

## GitHub Pages

1. Создайте публичный репозиторий `malmyzh-site` и загрузите содержимое этой папки в его корень.
2. В Settings → Pages → Build and deployment выберите GitHub Actions.
3. Запустите workflow Build Python site and deploy Pages во вкладке Actions либо отправьте коммит в main.
4. Адрес появится в результате workflow и настройках Pages.

Альтернатива без Actions: Settings → Pages → Deploy from a branch, ветка main, папка /docs. Готовая сборка включена. После изменений `app.py` пересоберите сайт.

Запасы 2021 года не выданы за добычу 2026 года. Корпоративные меры не выданы за доказанную эффективность. Общие экологические риски не выданы за зафиксированный ущерб. Доступ к карточке Росприроднадзора ограничен HTTP 403; это отмечено в библиографии.

Фотографии подписаны, прямые адреса — в `assets/image-sources.json`. Права на сторонние фотографии сохраняются за правообладателями; свободная лицензия для них не заявляется. Авторские схемы условны и не предназначены для навигации и инженерных расчётов.

Учебный неофициальный проект. Нет аналитики, cookies, внешних шрифтов, API-ключей и сторонних библиотек. Иллюстрации хранятся локально.
