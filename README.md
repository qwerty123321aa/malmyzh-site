# Малмыжское месторождение

[Открыть опубликованный сайт](https://qwerty123321aa.github.io/malmyzh-site/)

Информационный сайт на Python о географии, геологии, полезных ископаемых, значении и экологических вопросах Малмыжского месторождения в Хабаровском крае.

В обновлённой версии — семь реальных фотографий из галереи Малмыжского проекта АО «Тех Взрыв Инвест», просмотр снимков крупным планом, интерактивная карта OpenStreetMap, графики пересмотра запасов и схема среднего содержания меди в руде. У фотографий указаны источник и отсутствие подтверждённой даты съёмки. Сторонние водяные знаки сохранены.

12 страниц: главная, геология, расположение, запасы, добыча, экономика, экология, история, галерея, обновления, источники и поиск. Светлый редакционный дизайн с графитовыми секциями; локальные Manrope и Inter по SIL OFL. Старые адреса сохранены.

Модернизация 6 ноября 2026: Leaflet и OSM, Plotly с отложенной загрузкой и статическим запасным представлением данных, поиск по полным текстам, фильтры источников и фотографий, переключение кадров клавишами, полноэкранный просмотр, учебная геологическая схема, CSV, sitemap, robots, canonical и Open Graph. Тяжёлые библиотеки загружаются только при необходимости. Без сети карта и интерактивные графики могут быть недоступны; тексты и статические диаграммы сохраняются.

Аудит и план: `AUDIT.md`. Новые страницы и общий шаблон: `portal.py`. Оригинальные тексты: `app.py`. Функции интерфейса разнесены по `assets/portal.js`, `gallery.js`, `search.js`, `map.js`, `charts.js`. При добавлении страницы индекс поиска обновляется автоматически во время сборки.

## Запуск и сборка

Python 3.10 или новее. Сторонние библиотеки не нужны.

```sh
python3 app.py serve
```

Сайт откроется на http://127.0.0.1:8000. Для другого порта: `python3 app.py serve --port 8080`.

```sh
python3 app.py build
python3 app.py check
```

Python генерирует готовые страницы в `docs/`. Проверка проверяет локальные ссылки, якоря, наличие изображений, их описания, подписи и заголовки. В GitHub Pages Python выполняется на этапе сборки, а посетителям показываются готовые страницы. Workflow `.github/workflows/pages.yml` автоматически проверяет и публикует изменения из ветки `main`.

## Источники

Материалы проверены 5 ноября 2026 года. Полная библиография и ограничения сведений находятся в `sources.json` и на странице `sources.html`. Прямые адреса изображений — в `assets/image-sources.json`.

Данные о запасах 2021 года не представлены как добыча за 2026 год. Проектные меры защиты и общие риски отделены от результатов мониторинга. Координаты отметки на карте приблизительные, контур лицензии не показан. Карта загружается с OpenStreetMap; остальные фотографии и шрифты хранятся в проекте.

Права на фотографии сохраняются за правообладателями, свободная лицензия для них не заявляется. Фотографии получены с сайта подрядчика, на странице конкретного Малмыжского проекта; индивидуальный автор и дата съёмки там не указаны.
